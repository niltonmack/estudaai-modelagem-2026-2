Protótipo do painel do administrador (/painel) — layout aprovado em 2026-10-08. Casca do administrador da SPEC-001; dados das SPEC-003, 006, 008 e 009. Não é o app em produção. Home do aluno

O que esta tela mostra

  • Números: alunos cadastrados, acompanhamentos em andamento, trilhas pré-definidas publicadas e estado do agente LLM.
  • Avanço geral dos alunos: etapas concluídas ÷ etapas de todos os acompanhamentos (mesma regra do percentual de cada trilha).
  • Novos acompanhamentos por semana: trilhas iniciadas pelos alunos em cada uma das últimas 8 semanas, pela data de início.
  • Trilhas mais acompanhadas: quantos alunos acompanham cada trilha e o avanço médio deles.
  • Somente leitura: o painel não marca etapas nem altera contas. A API não muda: GET /acompanhamentos, GET /usuarios, GET /trilhas, GET /configuracao/llm.
