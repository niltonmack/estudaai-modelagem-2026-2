ESTUDAAI - REQUISITOS NÃO FUNCIONAIS (RNF)

RNF01 - Responsividade
A interface deve adaptar seu conteúdo para uso em computadores, tablets e smartphones.

RNF02 - Integração com LLM
O sistema deve permitir integração com uma API de modelo de linguagem, considerando OpenAI ou uma solução local baseada em Ollama.

RNF03 - Desempenho
As ações principais do sistema devem apresentar tempo de resposta inferior a 2 segundos, desconsiderando operações cujo tempo dependa diretamente de serviços externos de LLM.

RNF04 - Usabilidade
A interface deve apresentar navegação clara e consistente, permitindo que o aluno localize trilhas, etapas e informações de progresso sem exigir conhecimento técnico.

RNF05 - Segurança de acesso
Funcionalidades que manipulem dados pessoais, progresso ou administração do sistema devem exigir autenticação.

RNF06 - Controle de acesso
As operações administrativas de categorias, trilhas e etapas devem ser restritas a usuários com perfil de administrador.

RNF07 - Manutenibilidade
O código deve ser organizado em módulos e seguir boas práticas compatíveis com a arquitetura do Django, facilitando correções e evolução do sistema.

RNF8 - Compatibilidade web
O sistema deve funcionar nas versões atuais dos principais navegadores web usados em computadores e dispositivos móveis.
